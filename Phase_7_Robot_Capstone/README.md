# Phase 7 — Robot-Controller Capstone

**Target period:** May – June 2027

## Goal

Apply the foundations from earlier phases to a documented robot-controller project.

## Initial planning questions

- What behavior should the controller implement?
- What hardware and sensors are available?
- What are the timing and responsiveness requirements?
- Which components need interrupts, timers, or serial communication?
- How will the firmware be tested without relying only on a successful demonstration?

## Project milestones

- [ ] Define requirements and constraints.
- [ ] Draw a system/block diagram.
- [ ] Define firmware modules and interfaces.
- [ ] Implement the core controller.
- [ ] Test modules and system behavior.
- [ ] Document build, flashing, operation, results, and limitations.

The exact hardware and scope should be chosen based on available equipment and the knowledge gained in the earlier phases.
