# Phase 2 — STM32 Registers and Bare-Metal GPIO

**Target period:** January – February 2027

## Focus

Move from host-based C to firmware that interacts directly with MCU peripherals.

## Planned work

- Identify the exact STM32 MCU and board.
- Read the device datasheet and reference manual.
- Understand memory-mapped I/O and peripheral register fields.
- Configure GPIO through registers.
- Build, flash, and verify a small bare-metal program.

## Documentation checklist

Record the MCU part number, board, clock assumptions, toolchain, build commands, register addresses from authoritative documentation, and test observations. Do not assume register layouts are interchangeable between STM32 families.
