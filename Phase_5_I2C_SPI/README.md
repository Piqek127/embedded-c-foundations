# Phase 5 — I2C and SPI

**Target period:** April – May 2027

## Focus

Understand and work with two common serial peripheral interfaces.

## Planned work

- I2C bus concepts, addressing, and transactions
- SPI signals, modes, and transactions
- Peripheral configuration and driver structure
- Testing communication with a peripheral or suitable test setup

## Documentation checklist

Record the MCU, peripheral, bus configuration, connected device, wiring assumptions, transaction format, test procedure, and observed results. Use the peripheral datasheet and MCU reference manual for device-specific details.
