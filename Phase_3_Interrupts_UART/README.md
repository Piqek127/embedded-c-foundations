# Phase 3 — Interrupts, Timers, and UART

**Target period:** February – March 2027

## Focus

Understand event-driven firmware and peripheral timing.

## Planned work

- Interrupt fundamentals and vector tables
- Interrupt service routines and shared state
- Hardware timers and timing configuration
- UART configuration and serial communication
- Debugging and documenting timing behavior

## Documentation checklist

Record the exact MCU, clock configuration, peripheral configuration, baud rate where applicable, relevant register settings, test method, and observed results. Explain concurrency and shared-state assumptions.
