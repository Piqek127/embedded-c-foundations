# Phase 1 — C Memory and Data Representation

**Target period:** November 2026 – January 2027

This phase develops a practical understanding of how C values are represented and how programs access memory.

## Topics

- Bit operations and integer representation
- Pointers and pointer arithmetic
- Arrays and strings
- Stack and heap behavior
- Structures, padding, and alignment
- Memory-visualizer project

## Planned work areas

- `bit_operations/`
- `pointers/`
- `arrays_strings/`
- `stack_heap/`
- `structs/`
- `memory_visualizer/`

## Working rule

For each topic, include a small experiment that demonstrates the behavior, explain the result, and record any platform-specific assumptions. Avoid relying on undefined behavior as if it were guaranteed behavior.
